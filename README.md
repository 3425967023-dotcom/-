# 大数据分析及数据可视化

本仓库用于存放大数据分析与数据可视化相关的代码、数据集与笔记。

## 目录结构

```
.
├── README.md
├── .gitignore
├── data/          # 数据集（原始数据 / 处理后数据）
├── notebooks/     # Jupyter Notebook 分析文件
├── src/           # 分析与可视化源码
└── output/        # 图表、报表等输出结果
```

## 环境

- Python 3.13
- 常用库：pandas、numpy、matplotlib、seaborn、pyecharts

```bash
pip install pandas numpy matplotlib seaborn pyecharts
```
